01 / About

Bridging machine learning and production engineering

I am Abdel Rahman Milhem, a Data Science & Artificial Intelligence graduate from Al-Hussein Bin Talal University (2026). My focus lies at the intersection of applied machine learning and full-stack software development.

Too many AI models never leave Jupyter notebooks. My mission is building the end-to-end pipeline: training computer vision models (such as YOLOv8 and MobileNetV2), compressing and quantizing them via TensorFlow Lite (TFLite), and delivering them inside responsive, high-performance applications.

On the application layer, I engineer multi-platform experiences using Flutter and Dart, paired with Python APIs, Firebase, and Supabase for authentication, real-time database sync, and storage. I value clean code structure, agile teamwork, and dependable software that scales.
